# 🛒 Flipkart Products Analysis

Pricing, discount, and category analysis of ~10,000 product listings scraped from Flipkart.com.

## Problem Statement
Understand pricing strategy and discounting patterns across product categories on a major Indian
e-commerce platform — which categories are discounted most aggressively, how price relates to
discount %, and which brands dominate listings.

## Dataset
[Flipkart Products](https://www.kaggle.com/datasets/PromptCloudHQ/flipkart-products) — pre-crawled
subset of 20,000 products from Flipkart.com (retail_price, discounted_price, category, brand, ratings).

## Data Cleaning Steps
- Dropped malformed rows (source file has ~10k corrupted rows from unescaped multi-line text — filtered to ~9,965 clean, usable products)
- Extracted top-level `category` from the nested `product_category_tree` field using regex; rows with no real hierarchy marked "Unknown"
- Converted `retail_price` / `discounted_price` to numeric
- Computed `discount_pct` = (retail − discounted) / retail × 100
- Parsed `product_rating`/`overall_rating` ("No rating available" → NaN)
- Filled missing brand with "Unknown"

## Key Insights
- **Clothing** and **Jewellery** are the largest categories by listing count
- **Health & Personal Care Appliances, Sunglasses, Wearable Smart Devices** carry the highest average discounts (55–65%)
- Higher-priced items don't always mean lower discount % — no strong price-discount correlation
- Brand column has known data-quality noise in the source dataset (some "brand" values are actually colors, e.g. "Black"/"White") — flagged, not treated as ground truth in insights

## Dashboard Features
